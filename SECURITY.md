# Security Policy

## Project Status

Lune Bot has been discontinued since 2023 and is no longer maintained.

This repository is kept public for historical, educational, and archival purposes only. It should not be treated as production-ready software, and it should not be used as a secure or actively supported WhatsApp automation solution.

No new features, compatibility updates, dependency upgrades, or security patches are planned.

## Supported Versions

There are currently no supported versions of Lune Bot.

| Version / Period | Status |
| --- | --- |
| 2019–2023 project code | Deprecated and unsupported |
| Current repository state | Archived / historical reference only |
| Forks or modified versions | Not supported by the original maintainer |

## Security Updates

Because the project is discontinued, security updates are not guaranteed and should not be expected.

This includes, but is not limited to:

- vulnerable or outdated dependencies;
- broken compatibility with WhatsApp Web, OpenWA, Node.js, or third-party APIs;
- exposed credentials caused by local misconfiguration;
- unsafe deployment practices by forks or self-hosted copies;
- issues caused by running the bot on public servers or real WhatsApp accounts.

Anyone choosing to run, fork, or modify this code is responsible for reviewing, hardening, and maintaining their own deployment.

## Reporting a Vulnerability

If you find a vulnerability in this repository, please do not publish sensitive exploit details publicly.

However, because Lune Bot is no longer maintained, vulnerability reports may not receive a fix, release, or formal response. Reports should be considered informational unless the maintainer explicitly decides otherwise.

If the issue affects a fork, modified deployment, or third-party instance, report it directly to the owner of that fork or deployment. The original Lune Bot repository does not provide security support for external copies.

## What Not to Report

Please do not report:

- requests for new features;
- WhatsApp compatibility problems;
- installation or setup issues;
- dependency warnings without a confirmed security impact;
- problems caused by modified forks;
- abuse, spam, bans, or account restrictions caused by using WhatsApp automation.

These are outside the scope of this archived project.

## Responsible Use

This code interacts with WhatsApp automation libraries and may rely on unofficial behavior. Running automation against WhatsApp can break, trigger rate limits, or violate platform rules depending on how it is used.

Before running any fork or copy of this project, review the code carefully, rotate any exposed API keys, remove unused integrations, update dependencies, and test it in a controlled environment.

Do not use this project with sensitive accounts, production phone numbers, private user data, or systems where security and reliability matter.

## Disclaimer

This repository is provided as-is.

The original maintainer does not guarantee that the code is secure, functional, compatible with current platforms, or suitable for any specific purpose. Use of this repository, including any fork or self-hosted version, is entirely at your own risk.
